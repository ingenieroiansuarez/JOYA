# AUREA Jewelry Engine (AJE)
DesignDocument is authoritative for parametric features; imported sculptures retain immutable source mesh. Canonical mm, right-handed Z-up internally, explicit glTF Y-up transformation, meters in glTF; STL has no units so manifest specifies mm. Quaternions normalized; component IDs stable across regeneration; semantic anchors (ring.top, setting.seat) not transient face indices. Topological naming failures become unresolved constraints, never silently reattach. Build dependency DAG, reject cycles/dangling IDs, validate ranges and finite numbers, cache on canonical input digest + family version + kernel version + tessellation/DFM rules. Rebuild descendants only; atomic artifact publication. Precision CAD creates BREP solids; mesh operations preserve origin, scale and topology, repair if possible. Do not claim arbitrary mesh converts into editable CAD or watertight solid. Keep originals and provenance.

## Geometry interface
`regenerate(document, kernelVersion, tolerance) -> artifacts, metrics, diagnostics`; `preview(operation, baseRevision) -> diff, preview, warnings`; `validate(revision, rulesVersion, process, alloy) -> findings`; `export(revision, format, approvals) -> hash, unit, manifest`. FastAPI workers receive signed job refs, fetch snapshot, return result via internal API. Limits proposed 20MB import/1M faces for interactive tier; enforce decompression, timeout, CPU/memory quotas and path traversal protection. No generated Python or arbitrary CAD scripts from untrusted users. Allowlist operations and validate semantic parameters separately from JSON schema.

## Feature operations
create sketch (line/arc/spline), extrude, revolve, sweep, loft, union/subtract/intersect, transform, fillet/chamfer, shell, radial/linear/curve patterns, gemstone placement, engraving, relief, sculpt deform, mesh repair. Initial offline subset: ring, pendant, compatible setting and stone, material, transform, engrave preview, undo/redo. Advanced surfaces, sculpt brush and curved engraving follow hito 900. Exact volume uses BREP or validated closed mesh, non-overlapping solids by material; subtract intentional cavities, avoid double count of overlaps. Mass g = mm³ × density g/cm³ / 1000; alloy density configured, no estimate is assay. Gem mass from actual lot or clearly estimated ct; not metal density.

## .aurea archive
ZIP with manifest.json(schemaVersion, projectId, revisionId, hashes, engine versions, units), design.json, feature graph, constraints, materials, geometry master.brep / step, preview.glb, manufacturing bom/validation, references, renders, revisions. Reject symlinks/path traversal, archive bombs, missing hashes; don't overwrite project on import; create new draft. Public sharing strips proprietary files and private references by policy. STEP does not preserve native history reliably; STL/GLB no parametric history. SVG/DXF import closed profiles with explicit scaling; 3DM evaluate NURBS/mesh coverage. Export separate solids for different materials and stone seats; package only approved immutable revision.
