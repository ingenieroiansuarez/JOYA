# Infraestructura y runbooks
Local Windows: WSL2 + Docker Desktop, Android Studio/SDK, Node/Python toolchains pinned post-PoC. Compose reference starts PostgreSQL and Redis only, loopback bound; Keycloak, S3 emulator and app services added at hito 100 with pinned digests. `.env.example` is local-only; generate secrets, never commit actual values. Use `docker compose -f 25_INFRASTRUCTURE/compose.reference.yml --env-file 25_INFRASTRUCTURE/.env.local up -d`. Copy example then edit. Verify health and apply reviewed migrations; no data migration from demo into production. Do not expose host ports to LAN except dev API under intentional firewall rules. Android emulator 10.0.2.2, device adb reverse or restricted LAN TLS. No cleartext in release.

AWS: separate environments/account or strong isolation; Terraform state encrypted and access limited, plan approval, no secrets in state where avoidable. VPC public ALB + private ECS tasks/RDS/Redis; S3 block public access, KMS and versioning, lifecycle/backup, signed URL/CDN for approved media; worker roles limited to prefix and job callbacks. GPU capacity separate (EC2/ECS GPU or batch), CAD CPU scale by job age; budget alarms and rate limits. Keycloak managed deployment or equivalent OIDC reviewed. RDS PITR and snapshots, Redis recoverable cache, outbox replay, object replication/versioning if required. CloudWatch/OTel traces, alerts on p95 latency, queue age, error %, payment mismatch, inventory discrepancies, certificate anomaly, disk/DB connections, cost and backup age. No PII in telemetry.

## Runbooks
Deployment: review migration + backups, deploy compatible API/workers, smoke test sandbox, rolling release, monitor, roll back code if schema compatible otherwise roll forward. Pause production release if critical gate fails. Restore: provision isolated DB at requested point, verify row counts and reconciliation, object hashes, replay outbox idempotently, compare payment provider records, verify RPO/RTO, switch only with approval. Provider outage: open circuit breaker, show pending/stale, fallback only if permitted, no fake success. Queue stall: inspect job age and leases, pause consumer, retry bounded, DLQ review; don't delete jobs silently. Inventory discrepancy: freeze affected lot, investigate movements, dual approval compensation. Payment mismatch: disable release, reconcile provider, escalate; no manual status overwrite. Security incident: revoke keys/session, isolate workload, preserve logs, assess disclosure, restore and postmortem. All actions logged.
