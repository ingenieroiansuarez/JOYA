# Requisitos y trazabilidad
Las 184 respuestas se han normalizado sin cambiar su sentido. `hito_inicio` es una propuesta de primera entrega parcial, no una promesa de completar todo el requisito en ese hito. Todos siguen sin implementar en el producto. Los IDs son estables. Cada PR debe enlazar REQ, pantalla, contrato, prueba y evidencia. Una capacidad no puede declararse completa hasta cubrir todos los criterios acordados.
