# API baseline
Versión de contratos: ver `CHANGELOG.md`. Los estados salen de `08_STATE_MACHINES/machines.json` y las operaciones de diseño de `13_AI_PROMPTS_AND_TOOLS/tools.json`; el sobre de eventos de `07_DOMAIN_MODELS/event.schema.json`; no editar a mano los enums `*State`, `DesignOperation`/`Op*` ni `Event` (`python tools/contracts/check_contracts.py --emit`). Los códigos de error estables están en `errors.json`.

REST /v1; UUID; errores estructurados; ISO UTC. Bearer OIDC validado issuer/audience/exp; permiso por recurso en servidor. POST Idempotency-Key por actor+scope+hash del cuerpo; repetir devuelve resultado, mismo key distinto body =409. Los webhooks del proveedor no usan JWT de cliente: ruta separada con verificación de firma sobre bytes originales, dedup por eventId y replay window. El cursor es opaco, filtros permitidos, paginación limitada. WebSocket autenticado y autorizado por proyecto; eventos con secuencia, reconexión vía pull. No enviar precios internos a clientes. Trabajos 202, GET status y cancelación; descargar artefactos por URL firmada tras ACL. OpenAPI V1 es base de integración, no implementación ni cobertura final de todos los módulos. `operationId` estable para clientes generados. Validar schemas específicos de operaciones geométricas y herramientas IA, no aceptar JSON arbitrario. Los campos abiertos deben cerrarse antes de producción. Las rutas internas de worker y webhook se definen por adaptador.
