# QA strategy and evidence
Simulator tests are only reference tests. Product gates require actual NestJS/Python/Android/Web code. Use Vitest/Jest, pytest, Testcontainers PostgreSQL/Redis, OpenAPI contract generation/validation, Playwright web, Maestro Android + native tests, Storybook visual diffs, axe + TalkBack/manual, k6 performance, Semgrep/Trivy/SBOM/OWASP ZAP in isolated staging, geometry fixtures, AI golden set. Unit tests per domain invariants and failure paths. Integration real transactions, migration from previous release, duplicate/out-of-order webhooks, worker crash, artifact corruption. E2E roles and device matrix. No high severity security issue open for release unless documented accepted risk by owner; critical never accepted. No real charges in tests. Regression evidence stored per release, test case links REQ/screen/contract. CI gate on changes, production manual approval. RPO/RTO measured by restore drill. Geometry test threshold per family and workshop signed. Avoid arbitrary coverage as sole gate.
