# ADR-0016: Edición demo en el portátil del presentador
Estado: **propuesto** (hito 600, 2026-11-25). Requiere la aceptación de ian con el hito.

Contexto: 29_DEMO_SCENARIO pide APK y panel con "el mismo backend aislado", datos físicamente separados de producción y reinicio por script autorizado. Por decisión de ian (2026-11-25) no hay presupuesto: nada de servidores en la nube, dominios ni certificados pagos. La demo corre en el portátil de quien presenta y el teléfono se conecta por USB.

Decisión:
- Pila demo propia (`compose.demo.yaml`, proyecto `aurea-demo`): PostgreSQL `aurea_demo`, Valkey y Keycloak (realm `aurea-demo`) con volúmenes, puertos y carpeta de artefactos distintos de los de desarrollo (`compose.yaml`, `aurea_local`). Variables en `.env.demo` (git-ignored), generadas por `pnpm demo bootstrap`. Los procesos hijos de `pnpm demo` no heredan variables AUREA del shell.
- `AUREA_ENV=demo` admite http **solo en loopback** (`127.0.0.1`/`localhost`) para emisor OIDC, API y panel: el teléfono llega por `adb reverse`, así que el tráfico no sale a la red. Fuera de loopback, demo exige https como antes; producción exige https siempre.
- Realm demo sin cliente CI, con personas sintéticas (`demo.cliente`, `demo.equipo`, `demo.asesor`, `demo.disenador`, `demo.almacen`, `demo.inspector`) y correos `@aurea.invalid`.
- Reinicio: `pnpm demo reset --yes` borra y recrea solo la base `aurea_demo` en loopback (comprueba `AUREA_ENV`, host, nombre en la URL y `current_database()` antes de borrar).
- Pagos, AURA y precios siguen simulados y etiquetados (ADR de hitos 400/500, decisión sin presupuesto).

Alternativas rechazadas: backend demo en la nube (costo); compartir la base de desarrollo con un esquema distinto (no es separación física); https con certificado autofirmado en el teléfono (instalar una CA de usuario en Android es frágil y peor práctica que loopback por USB).

Consecuencias: la demo depende del cable USB y del portátil encendido. Sin USB, la app demo usa un catálogo local etiquetado como tal (sin fingir conexión). Un backend demo alojado con https queda para cuando haya presupuesto; entonces se vuelve a exigir https y este ADR se revisa.
