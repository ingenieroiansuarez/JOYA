# Workshop, manufacturing and quality
RouteTemplate versioned per process (artisan, casting, 3D print pattern, CNC, laser, outsource); work order references immutable approved design, BOM and package hash. Task graph with prerequisites, resource qualifications, location, estimate minutes, dates, assigned worker, status and actual time. No cyclic dependency. Schedule earliest start from dependencies, availability, material allocation and capacity; recalculation suggests changes, never changes promised dates automatically. Worker UI offline caches assigned tasks, appends time/evidence/incident; server validates and reconciles. Critical custody and inventory moves need online authority; no hidden duplicate consumption.

Release gate: accepted quote / order, required advance confirmed, materials reserved or allocated per route, approved DFM and professional sign-off for same revision, confirmed size, authorized release actor. No direct machine operation. Create package CAD/mesh, BOM, drawings, tolerances, instructions, revision hash, approvals, external vendor subset. Rework creates linked task and cost; nonconformity blocks QA. Quality checks by route: dimensions, actual mass, materials and assay evidence, gemstone ID, prongs/setting, engraving, finish, external certificate, packaging. Missing evidence or failed critical check blocks final approval. Inspector cannot self-approve critical task when separation required.

Metal balance per job = inputs − finished − recoverable − irrecoverable − retained WIP. Compare within configurable metrology tolerance; discrepancy investigation, adjustment ledger not overwrite. Recoverable scrap held separately by lot/assay; refining receipt records yield. Customer goods segregated, never fungible with house stock without consent. Gem units track custodian, condition, transfer and placement into item. Certificate issued only after QA; public QR verifies opaque certificate ID, issuer and status without owner PII; revoked/superseded records remain. External lab cert linked, do not claim independent authenticity from internal certificate.
