# CI/CD
GitHub Actions short-lived branches, PR protected main, required reviews, tags signed when possible, changelog. First workflow validates handoff fixtures and simulator. Extend at 100: install locked deps with pnpm frozen lockfile, lint/typecheck, unit, schema validation, integration containers, build, E2E and visual; separate Android runner with JDK/SDK/NDK; Python matrix pinned; security and SBOM artifacts; stage deployment via OIDC short-lived cloud role. Production environment approval, never on PR, no secrets in logs; provenance and checksum APK/AAB. Reproducibility: lockfile, toolchain matrix, build version, commit SHA, environment. Failure blocks release, artifacts immutable. EAS/Gradle signing separate demo/prod package IDs and keys; no debug flag or simulators in prod. CI reference workflow only runs simulator, not product builds.
