# AURA Intelligence
Single user-facing assistant. Logical roles MUSE (creative concepts), FORGE (CAD proposals), GEMOLOGIST (materials, never authenticity claims), STYLIST (occasion/style), CONCIERGE (support/sales), CURATOR (collections), RESTORE (reference/reuse), INSPECTOR (explain DFM), BUSINESS (authorized analytics), MARKETING (draft assets). One gateway routes tasks based on capability registry; models are replaceable. Do not require an agent framework. Each adapter implements generate, poll, cancel, normalize, estimateCost, health, capabilities. Registry fields: provider, modelId, version, modalities, input/output limits, region, retention, commercial rights, latency benchmark, price unit, supported tool schema, fallback eligibility. Verify commercial terms, not assumed. OpenAI/Anthropic/Gemini for LLM; Meshy/Tripo for mesh candidates; image/STT/TTS adapters evaluated. No model versions fixed here.

## Pipeline
Authenticate + check project ACL/consent → classify task → extract structured design brief → reserve quota and cost cap → retrieve allowed docs or authoritative data → choose capability → generate proposals → validate outputs and policy → user accepts change → server performs typed operation on expected revision → log evidence and actual consumption. Separate conversational and geometric history. Store source refs with retrieval date; RAG for policies/documentation; pricing/inventory retrieved via authoritative APIs, not vector search. Isolate tool results as untrusted data, no prompt injection actions. Never expose other customers' data. No provider API key in app.

## Generative routes
A: text → structured parameters → compatible family; B: concept images → mesh generation (async) → import scale/repair → DFM and manual review; C: hybrid ring/shank + sculpture + gems with known dimensions. Offer N configurable proposals (default 3, max per policy). Preserve locked user choices; changing natural to lab gemstone requires explicit confirmation. Image is concept, mesh is not certified CAD. Reuse only with rights and consent; reverse engineering needs manual scale and actual inspection.

## Consumption
Quota ledger tracks reserved/spent/released tokens/images/jobs; idempotency per request. Enforce per actor/day/org caps, timeouts and max retries; fallbacks only if allowed privacy and cost, never silently send sensitive files to different region/provider. Cached artifacts scoped by owner/permissions and version; no cross-customer reuse of private inputs. Demo adapters return deterministic fixture outputs with simulated banner. Real provider disabled unless configured. Monetization later: quota + premium charges with explicit quote, optional design fee credit.

## Evaluation
Golden set ≥30 cases for pilot: classic ring, hybrid dragon, incompatible gem seat, prompt injection in attachment, natural-to-lab substitution, budget change, unavailable item, multilingual prompt, cancellation, provider outage, private design, stale revision, false gem claim. Measure schema validity, action correctness, source accuracy, edit success, visual fidelity, latency p50/p95, cost and manual acceptance. Block on unauthorized actions, fabricated certification, uncontrolled spend or unvalidated geometry. Regression compare fixed inputs across provider versions; subjective render scored by human with rubric 1–5; threshold proposed ≥4 on key aesthetic cases. No generated code executed by production worker.
