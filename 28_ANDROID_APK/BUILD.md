# Android build contract
Hito 100 create Expo dev build with Expo Router; app identifiers com.aurea.customer.dev / .demo / production identifier approved by jeweler. Native modules Kotlin/NDK for renderer and camera, Expo config plugin or maintained native project; not Expo Go. Verify actual Expo/RN/Gradle/JDK/NDK/Filament version compatibility, lock toolchain. Build development via Gradle or EAS; demo internal distribution signed APK; production AAB for Google Play. EAS template `eas.reference.json` copy into actual app and add approved project ID, package names, secrets/env mapping. `eas build --platform android --profile demo` after EAS init, auth and signing; alternative Gradle assembleRelease with approved signing config. Local Gradle on Windows or supported environment; no promise of EAS local on Windows. Install with `adb install -r path.apk`; inspect logs and smoke. APK must connect to demo backend via configured URL; data isolated and simulated banner permanent. No provider keys in artifact. Build offline catalog and preview assets; regenerate app after native changes. Record app version, build code, commit, SHA256, signing fingerprint, devices tested, backend version. Test clean install, upgrade, airplane mode, permissions denied, cold start, low memory, sign-out, no real payment. Production verify Play policy/target SDK current requirements at release, privacy disclosures and store review. No APK generated by this handoff.
