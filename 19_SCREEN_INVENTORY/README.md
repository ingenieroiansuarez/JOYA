# Inventario de 410 vistas funcionales
6 superficies: AND Customer, WEB Command, CAD Master, WOR Workshop, POS Showroom y SUP Supplier. IDs y rutas propuestas. Varias vistas serán estados/modales de una misma ruta real; no implementar todas como apps independientes. `contract_candidate` identifica contrato de referencia del grupo, no cobertura completa; PLANNED indica módulo aún sin endpoint especificado. En cada slice cerrar campos, acciones, contratos y permiso exacto por acción, revisar rol invitado para edición local sin persistencia remota, estados y pruebas individuales. No se trata de mockups finales de cada pantalla. Los primeros flujos detallados están en 20_UX_FLOWS.
